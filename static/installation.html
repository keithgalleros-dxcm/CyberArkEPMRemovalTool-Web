Request elevation for this console

A web page cannot grant account rights. On Windows, request a local UAC prompt and have an authorized administrator approve it. Approval relaunches this console as administrator; it does not add your account to an administrators group or start removal.

Checking local privileges…

Manual steps and organizational approval
  1. If you do not have an administrator account or UAC is blocked, contact IT or use your organization’s approved CyberArk EPM / JIT elevation workflow. This app does not submit a service-desk ticket or approve entitlement requests.
  2. For manual relaunch, stop the current console with Ctrl+C in its terminal. On Windows, paste the command below into PowerShell. On macOS, paste it into Terminal and enter the password only in the native terminal prompt.
  3. Open this same local URL again. Confirm the privilege indicator, review the agent and explicitly authorize removal.
Checking the local launch command…

Windows approval may require an administrator to enter credentials on the secure desktop. API-enabled consoles require a manual restart so an administrator can preserve their configuration. Linux inventory guidance does not require elevation.
