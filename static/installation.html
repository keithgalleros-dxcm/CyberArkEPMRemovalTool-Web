Checking this PC connector…

Open the downloaded installer on this PC. Setup handles Python detection, file extraction and startup. On macOS/Linux, run sh Install-connector.sh in Terminal.

How installation works
  1. Click Install connector on the PC or VM you want to manage. Open the downloaded installer there; browsers require this user action.
  2. Windows: open Install-connector.cmd. Setup checks Python 3.11+, provisions a private Python runtime if missing, copies connector files into your user application folder and starts it automatically.
  3. macOS/Linux: run sh Install-connector.sh in Terminal. Setup detects Python, installs it if needed using the supported system installer/package manager (sudo approval may be required), and starts the connector.
  4. No manual extraction or copying into the Python folder. Return here and confirm the endpoint hostname. Later agent changes still require explicit confirmation and local UAC/sudo.

Setup logs stay in the connector installation folder. Windows adds a Start menu reconnect shortcut. No connector service or login startup is registered. Enrollment is private, single-use and expires after 10 minutes; if setup takes longer, use a fresh installer. The connector makes outbound requests; no inbound endpoint port is needed.
