ADMINISTRATOR ACCESS

Request elevation for this console

A web page cannot grant account rights. On Windows, request a local UAC prompt and have an authorized administrator approve it. Approval relaunches this console as administrator; it does not add your account to an administrators group or start removal.

Manual steps and organizational approval
  1. If you do not have an administrator account or UAC is blocked, contact IT or use your organization’s approved CyberArk EPM / JIT elevation workflow. This app does not submit a service-desk ticket or approve entitlement requests.
  2. For manual relaunch, stop the current console with Ctrl+C in its terminal. On Windows, paste the command below into PowerShell. On macOS, paste it into Terminal and enter the password only in the native terminal prompt.
  3. Open this same local URL again. Confirm the privilege indicator, review the agent and explicitly authorize removal.
Checking the local launch command…

Windows approval may require an administrator to enter credentials on the secure desktop. API-enabled consoles require a manual restart so an administrator can preserve their configuration. Linux inventory guidance does not require elevation.

Connect an AI tool or local automation

The API runs on the endpoint at http://127.0.0.1:8765. A cloud AI service cannot reach your colleague's loopback address. Run its connector or client on the managed endpoint.

  1. Generate a key: python -c "import secrets; print(secrets.token_urlsafe(32))"
  2. Set EPM_API_KEY in the environment before starting python app.py.
  3. Configure your integration with the local base URL and bearer key. Import the OpenAPI schema below.
  4. Read endpoint status and ask the operator to confirm the hostname and agent before requesting removal.
OpenAPI 3.1 schema ↗

Integration endpoints

MethodRoutePurpose
GET/api/v1/statusEndpoint identity, agents, privilege and current operation
GET/api/v1/platformsPlatform and distro page catalog
POST/api/v1/uninstallExplicitly confirmed removal on the matching endpoint

Send Authorization: Bearer <EPM_API_KEY>. POST requests also need Content-Type: application/json. Browser origins are rejected on integration routes. API access is disabled until a key is configured.

Read status with Python

import json, os, urllib.request
request = urllib.request.Request(
    "http://127.0.0.1:8765/api/v1/status",
    headers={"Authorization": "Bearer " + os.environ["EPM_API_KEY"]})
with urllib.request.urlopen(request) as response:
    print(json.load(response))

See examples/client.py in the public repository for status polling and a removal request that requires explicit operator confirmation. Only one removal runs at a time. Operation state is in memory and resets when the server restarts.

Installation integration

Use GET /api/v1/packages for the redacted catalog and compatibility checks. Use POST /api/v1/install with package_id, hostname, target_platform and confirmation: INSTALL after operator approval. Administrator/root privileges are required. Keys and configs stay in private local storage.
