Checking local distribution…

Removal readiness

  1. Identify the CyberArk product name, package name and installed version from your software inventory or administrator.
  2. Record the Linux distribution and version shown above. Verify that version against the product's support matrix.
  3. Get the documented uninstall procedure and any required approval or secure token from your CyberArk administrator.
  4. Plan a maintenance window and test the procedure on a disposable endpoint before production use.

No package removal commands are generated. EPM, Identity and Privilege products have different removal procedures.

MANUAL OPTION · DISPLAY ONLY

Manual command-line instructions

Copy these commands into a terminal on the endpoint you intend to manage. Copying a command does not execute it. The console does not track removals started in a terminal; rescan afterward.

Read-only Linux identification commands are available below. The installed CyberArk product and its supported uninstall procedure are still unknown, so no Linux removal command is supplied. Package matches are candidates for investigation and do not prove that a package is the EPM agent. No matches can also mean the software was installed outside the package manager.

Identify the Linux distribution

cat /etc/os-release

Check available package inventory tools

command -v dpkg-query rpm pacman

DEB-based systems: inspect package inventory

dpkg-query -W -f='${binary:Package}\t${Version}\n' | grep -Ei 'cyberark|idira|viewfinity|epm'

RPM-based systems: inspect package inventory

rpm -qa --qf '%{NAME}\t%{VERSION}-%{RELEASE}\n' | grep -Ei 'cyberark|idira|viewfinity|epm'

Arch-based systems: inspect package inventory

pacman -Q | grep -Ei 'cyberark|idira|viewfinity|epm'

Share the product name, installed version and distro version with your CyberArk administrator, obtain the exact vendor uninstall procedure, and validate it on an approved test endpoint. Avoid generic purge or file-deletion commands.
