MANUAL OPTION · DISPLAY ONLY
Manual command-line instructions
Copy these commands into a terminal on the endpoint you intend to manage. Copying a command does not execute it. The console does not track removals started in a terminal; rescan afterward.
Open Terminal on the Mac. The full uninstall uses the installed vendor helper and requires an administrator account for sudo. Use the token-file variant if EPM self-defense requires a token.
Terminal: full uninstall without a token
sudo "/Applications/CyberArk EPM.app/Contents/Helpers/CyberArkEPMUninstall" -full
Terminal: full uninstall with a token file
sudo "/Applications/CyberArk EPM.app/Contents/Helpers/CyberArkEPMUninstall" -full -token "/absolute/path/to/epm-secure-token.txt"
Replace the absolute token-file path with your vendor-issued secure token file. Restrict its permissions to the owner (chmod 600 /absolute/path/to/epm-secure-token.txt) and handle it according to your organization’s secret-retention policy. Do not paste tokens into shell history. Follow any vendor dialogs, then rescan this endpoint.
