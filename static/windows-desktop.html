MANUAL OPTION · DISPLAY ONLY
Manual command-line instructions
Copy these commands into a terminal on the endpoint you intend to manage. Copying a command does not execute it. The console does not track removals started in a terminal; rescan afterward.
Open CMD or PowerShell as administrator. Replace {PRODUCT-GUID} with the exact MSI identifier shown under Review installation. Use a vendor-issued secure token when self-defense requires it.
PowerShell
Start the session below, then paste the removal script. The execution-policy option applies to this new process; it does not grant administrator privileges, override enforced Group Policy, or disable EPM self-defense.
1. Start PowerShell with execution-policy bypass
powershell.exe -NoProfile -ExecutionPolicy Bypass
2. Full uninstall with a masked token prompt
$productCode = '{PRODUCT-GUID}'
if ($productCode -notmatch '^\{[0-9a-fA-F]{8}-(?:[0-9a-fA-F]{4}-){3}[0-9a-fA-F]{12}\}$') {
    throw 'Replace {PRODUCT-GUID} with the exact selected MSI product GUID first.'
}
$secureToken = Read-Host 'Vendor EPM secure token (leave blank if not required)' -AsSecureString
$token = [Net.NetworkCredential]::new('', $secureToken).Password
try {
    if ($token -match '["\r\n]') { throw 'Invalid token character.' }
    $arguments = "/x $productCode FULL_UNINSTALL=YES /qn /norestart"
    if ($token) { $arguments += ' SECURE_TOKEN="' + $token + '"' }
    $result = Start-Process -FilePath "$env:SystemRoot\System32\msiexec.exe" -ArgumentList $arguments -Wait -PassThru
    "MSI exit code: $($result.ExitCode)"
} finally {
    $token = $null
    $arguments = $null
    $secureToken.Dispose()
}
Command Prompt (CMD)
Use the first command when no secure token is required, or the second when self-defense requires one. Replace all placeholders before running. For tokens containing CMD expansion characters such as % or !, use the PowerShell prompt above.
CMD: full uninstall without a token
msiexec.exe /x "{PRODUCT-GUID}" FULL_UNINSTALL="YES" /qn /norestart
CMD: full uninstall with a vendor token
msiexec.exe /x "{PRODUCT-GUID}" FULL_UNINSTALL="YES" SECURE_TOKEN="REPLACE_WITH_VENDOR_TOKEN" /qn /norestart
These commands request full removal and suppress automatic restart. MSI codes: 0 successful, 3010 restart required, 1641 restart initiated. Other codes need investigation; 1605 means the selected product is not installed. Check the selected registration again and plan a restart before reinstalling.
Inline CMD tokens may appear in command history. Even prompted tokens can be visible to privileged process inspection and vendor logs.
